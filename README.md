# PostFedora
**A post-install tool for Fedora 43+**

### Does the next things:
- Add a curated plug'n play printing support.
- Adds RPM Fusion Repos, the most important thing though.
- Install VLC and SkanLite.
- Adds Multimedia Support from RPM Fusion recommendations(NVidia not yet supported).
- Also GIT and Curl.

### What versions Supports?
By the moment **ONLY SUPPORTS Fedora 43**, but I put the list just because yes.
- Fedora 43 (KDE Plasma recommended).

### How I do use it?
To get help run ```runme.sh```, and you'll get the params to select your hardware. Just make sure of type sudo before :D,
anyways if you're not root it will close with exit code 1 and it will ask you.
